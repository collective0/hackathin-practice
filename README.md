# Hackathon Practice

Next.js starter for a three-person hackathon team. No product features are
implemented yet.

```sh
npm ci
npm run dev
```

Open the Local URL printed in the terminal (normally http://localhost:3000).
Use Node.js 24 LTS and npm 11. No environment variables are required yet.

See [PROJECT.md](./PROJECT.md) for project structure, technology stack,
verification commands, and branch collaboration rules.
